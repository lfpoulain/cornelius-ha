# Cornelius (bêta)

La branche `beta` de Cornelius, le miroir intelligent de la famille : les fonctions en cours, avant leur publication. Elles peuvent être incomplètes ou cassées.

## À savoir

- Pour un miroir de tous les jours, installez plutôt **Cornelius**, qui suit les versions publiées.
- La bêta a ses propres données et ses propres ports (`3444` en HTTPS, `3001` en interne) : elle peut tourner à côté de la version stable. La base de l'une ne passe pas dans l'autre.
- Les satellites audio se connectent au premier Cornelius qui répond : avec les deux en marche, donnez-leur une adresse fixe.

Voir l'onglet **Documentation** pour la mise en route.
